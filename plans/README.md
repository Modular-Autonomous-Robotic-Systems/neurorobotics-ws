# Plans Index

This directory is the **committed change ledger** for the Neurorobotics Workspace (`NRT_WS`) — one document per feature/task produced by the `nrt-RandD-workflow` (investigate → plan → validate → implement). Each file records the motivation, the changes made, usage, and the validation strategy, and stands as durable history of how the project evolved. Together with `context/` and `ARCHITECTURE.md` these files form the project's knowledge base / digital twin.

> **Maintenance rule:** every non-trivial task writes or updates a plan here (see `CLAUDE.md §5`). During development a plan may carry investigation and validation detail. On completion it is rewritten as a clean change-record, and that rewrite is a **subtraction of review and design-iteration artefacts only, never a summarisation**. Every code snippet, design decision, rejected alternative with its reason, backwards-compatibility analysis and validation check is retained in full, and what goes is the revision markers, the reviewer-facing wording, the feedback rounds and the resolved uncertainty. Durable findings additionally move into `context/`. The full rule is in the `nrt-RandD-workflow` skill, Phase 6. Submodules may keep their own `plans/`; when Claude is invoked at a submodule root, that submodule's `plans/` is used.

## How to use this index

1. Skim the table below to see prior/ongoing work relevant to your task.
2. Open the linked plan for the full change-record before re-deriving history from `git`.
3. After finishing a task, add or refresh the plan file and its row here.
